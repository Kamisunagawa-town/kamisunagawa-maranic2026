北海道・上砂川町で開催する「ぐるっと紅葉マラニック」の大会特設サイトです。

## 🌐 公開URL

https://kamisunagawa-town.github.io/kamisunagawa-maranic2026/

## 📅 大会概要

- 開催日：2026年10月10日(土) 雨天決行
- 会場：上砂川岳温泉パンケの湯（スタート＆ゴール）
- 募集期間：2026年7月1日〜8月31日

## 🛠 構成

- `index.html` … サイト本体（HTML/CSS/JSすべて1ファイル）
- `images/` … 画像・動画素材
  - `images/aid/` … エイド写真（aid00〜aid08.jpg）
- `sitemap.xml` … Google検索用サイトマップ

## ✏️ 更新時のメモ

### エイド画像の公開日を変えるには
`index.html`内の各エイドカードの `data-reveal="2026-07-10T00:00:00+09:00"` の日付を変更します。
公開日になると、自動的にぼかしが外れます。

### お知らせバナーの公開日
`index.html`末尾のスクリプト内 `reveals` の配列で管理しています。

### 記念Tシャツのぼかしを外すには
記念Tシャツのカードの `<div class="perk coming">` から `coming` を削除します。

### お知らせバナーを追加するには
スクリプト末尾の `reveals` 配列に、日付とメッセージを追記します。
設定日から7日間、自動で表示されます。

### カウントダウンの日付
スクリプト内の `OPEN_DATE`／`EVENT_DATE`／`EVENT_END` で管理しています。
